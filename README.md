# Noubhar Ahmad · Portfolio

Static site, no build step. Files:

- `index.html` – the whole page (styles and script inline)
- `assets/headshot.jpg` – portrait used on the page
- `assets/headshot-square.jpg` – square crop for LinkedIn / profile photos
- `assets/cv.pdf` – linked from the "Curriculum vitae" button

## Publish on GitHub Pages

1. Create a public repository, e.g. `noubhar-ahmad.github.io` (gives you https://noubhar-ahmad.github.io) or any name (gives https://<username>.github.io/<repo>/).
2. Upload everything in this folder to the repository root (Add file → Upload files).
3. Settings → Pages → Build and deployment → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` → Save.
4. The site is live in a minute or two at the address shown on that page.

To update the CV later, replace `assets/cv.pdf` with a file of the same name.
